# SORA Cars live staking qualification, November 20, 2026

**Live XOR staking remains disabled.** The signed validator has no calibrated gas tariff for Stock verification. It rejects settlement even when the stake is zero. Public Taira also serves a different genesis and profile, and the tested released wallets cannot authorize this game’s settlement. The corrected browser transport and full native proof both passed their local checks.

The committed summary contains signed revisions, test results and SHA-256 digests. Detailed logs and captures linked under `output/` live in the qualification workspace. The protocol arithmetic and its input table are included in the repository. ## Protocol review

Claude Fable 5.2 at xhigh and an independent source review checked the transcript order, numerical security terms, lookup discrepancies, shifted OOD claims and folding geometry. All 24 native and 144 generic configurations passed the parameter checks. A joint row-list bound and a weighted folding argument supply a candidate interactive proof. The original correlated-agreement theorems support its curve and weight terms. The weakest conditional native round is the final query selection at 130.150 bits. Charging the prover and the one honest verification separately gives a conditional 129.149-bit lower bound for one fixed false statement in the classical framed random-oracle model. A deployed 128-bit soundness claim still requires independent review of this reduction, the circuit’s implementation of the integer race rules, and the ledger adapter. Core and the proof engine agreed on all 604,836 simulated ticks and 100,806 checkpoints across 96 cases. These comprised 93 distinct histories. Every track and roster exercised all 64 legal control masks. The comparison covered 192 finish crossings and 21 removals. Nine complete reference traces also satisfied the native checkpoint circuit, including an eight-car, 8,100-tick history on each track. These are sampled controller and circuit results. ## Four-validator settlement and finality

The local four-peer fixture runs the frozen validator executable, SHA-256 `bc720dd5a201c77eb24fe583c601281bb420d7d1ee37247d7eb1d950d03b148d`, and its matching native CLI, SHA-256 `c519444e9d21769495a23833e7be3c0f39bc77749d5ed3c6b5a077caa0784696`. Its scenario calls for a two-driver zero-stake race and a separate lobby advertising a positive stake. The latter checks the normal Join result and the resulting custody. Historical settlement at height 61 used an earlier runtime. [Historical and offline evidence](../output/reviews/live-staking-qualification-20261120/network/prior-and-offline-evidence.json)

The frozen Core function `compiled_execution_proof_tariff_v1` returns `MissingTariff` for every profile. Both `SettleGameSessionV1` and `VerifyExecutionProofV1` call it before proof verification. An unpriced instruction incurs 128 gas for refusal. The cutoff applies to every stake amount and registration status. Producing an accepted settlement and a finality certificate for it therefore requires a successor with a calibrated, immutable tariff for this exact profile. Its price must cover maximum verifier, record, history and settlement work within validator block capacity. [Frozen Core tariff](../../.iroha-port-worktrees/race-proof-native-20261119/crates/iroha_core/src/execution_proofs/metering.rs) · [Instruction metering](../../.iroha-port-worktrees/race-proof-native-20261119/crates/iroha_core/src/gas.rs)

All six native metering tests passed, including a zero-stake settlement refusal before record authentication, with state and receipt storage checked. In three separate processes the signed debug CLI verified the valid full proof with two workers using 4.12–4.22 seconds of process CPU and 79.0–80.9 MiB peak resident memory. These measurements cover standalone verification on ARM64 macOS. A block also has to authenticate the ledger history, execute the instruction and preserve room for consensus. [Six tests and three measurements](../output/reviews/live-staking-qualification-20261120/metering/results.json)

The signed Core verifier also accepted the full proof with its 438,053-byte race record, 1,349 archived checkpoint anchors and eight signatures on the selected checkpoint. Three runs on an Apple M4 Max used 7.10–7.41 CPU seconds each. The record allowance is 4,751,885 bytes. A tariff still needs production-validator measurements covering the largest permitted records and proof layouts, custody writes, and blocks containing other transactions. The verifier also retries field sampling and duplicate query positions. Its cryptographic tail estimate leaves the practical worst-case execution cost open. ## Wallet and SDK interoperability

The signed game used an unauthenticated Connect session-status request to obtain large-message limits. The deployed endpoint returned HTTP 400, and its authorized session response also omits those limits. The game successor consults the public, network-pinned game capability that covers the encrypted frame, buffer and downstream transaction limits. The first transport fix counted the SDK’s 216-byte ingress overhead. It passed all 776 application tests and its production build. The subsequent native relay check below established a 472-byte overhead at egress, so the ordinary 64,000-byte frame supports a maximum 63,528-byte signing payload. The retained game build also lacks an explicitly configured spending profile. Providing a reviewed profile to a future release would still leave the local cryptographic qualification and network identity checks in force. [Wallet test results](../output/reviews/live-staking-qualification-20261120/wallet/signed-successor.json)

The signed SDK rejected both the full native request and the verified proof because its Stock codecs allowed 900 checkpoint states. Native Stock allows 8,100 ticks in six-tick batches. The SDK successor derives its 1,350-checkpoint bound from that geometry and retains the separate Touring bound. The game’s settlement builder also produced a **2,719,809-byte** canonical unsigned transaction using the CLI-verified outcome. The original game emits a 2,720,025-byte encrypted signing request. Torii forwards a 2,720,281-byte frame. These bytes belong to the fixture network (`97104d6d…`).
