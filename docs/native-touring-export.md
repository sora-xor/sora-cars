The native CLI now exposes the existing Touring S1 computation through `export-touring-kernels` and `export-touring-parity`. Both commands run without wallet configuration and publish complete JSON to new destinations. The browser generator installs the native output after checking its executable, closed source inventory and complete reference corpus. See the [generation workflow](native-browser-generation.md).
