Read-only source assessment. This is a classification of plausible reduction requirements, not cryptanalysis, a complete security proof or an implementation change.

The native [Hash representation](/Users/takemiyamakoto/dev/iroha-sora-cars-native/crates/iroha_crypto/src/hash.rs:36) stores 32 bytes but forces the final byte's least-significant bit to one. Both `new` and `new_from_chunks` call `finalize_blake2b`, which applies that marker ([constructors](/Users/takemiyamakoto/dev/iroha-sora-cars-native/crates/iroha_crypto/src/hash.rs:117), [finalization](/Users/takemiyamakoto/dev/iroha-sora-cars-native/crates/iroha_crypto/src/hash.rs:190)). Thus computed outputs have at most 255 variable bits. This is neither unmodified BLAKE2b-256 output nor a defect in canonical decoding.

Under an ideal uniform marked-hash model, a generic classical collision search takes work on the order of `2^127.5`; for sufficiently small query count `q`, collision probability is approximately `q(q−1)/2^256`. Finding a different input for an independently fixed target has a different ideal bound, approximately `q/2^255`. These are model calculations, not measured attacks, exact bit-security claims or reductions for the complete protocol. Multiple targets, adaptive choices and composition change the accounting.

**Recommended wording:** “Some native identities have 255 variable output bits. Wherever the proof relies on collision resistance for adversarially chosen objects, its concrete analysis must use that marked output space. Fixed-target and extraction requirements need separate analysis. The observation establishes neither a practical attack nor a failure of the complete proof system.”

A strict at-least-128-bit composition claim must not silently count these values as unmodified 256-bit hashes. Conversely, assigning 127.5-bit security to every use would be unjustified. Domain separation distinguishes roles but does not expand output space. A later 48-byte PCS/transcript digest does not restore information already lost if it receives only a marked root; where it independently binds the original data, that additional check must be modeled explicitly. Digest width alone does not qualify the PCS either.
