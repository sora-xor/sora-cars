The caller supplies one canonical native `GameReplayExportRequestV1` containing
the original independently selected network/finality pins and explicit public
gameplay evidence. Torii reads the exact retained finality chain, carrier, merge
entry and complete game record from Kura. It stages a complete replay before
returning a successful binary response. Missing retention or a mismatched
selection is an error.

The original request explicitly selects `street` or `stock_race`; the browser,
SDK and native verifier must agree on that selection. Qualification compares
the exact Rust-generated canonical request, evidence and export-envelope codec
vectors for each computation. A different selector cannot relabel an existing
replay. Stock proof files contain one canonical `ExecutionProofEnvelopeV1`,
bounded by the native 4 MiB envelope limit plus canonical framing; Street keeps
its separate component-proof format. Both use the generic game replay facility
and the original independently pinned verification request.

The node cannot recover unrevealed controls from commitments. The proof record
office therefore takes a separate native evidence file for a Torii download.
Local Street practice JSON and Stock room drafts are not accepted substitutes.
After exact download completion to an owned OPFS file, the existing public-data
worker receives that replay and the original request. Independent verification
uses the native CLI with the same request; browser transport receipts remain
endpoint-reported.

Default node limits are one concurrent export, 256 MiB output, 1,024 finality
heights, a 10-second request-body deadline, 30-second export deadline and
60-second download deadline. The request envelope allows at most 16 MiB + 8 KiB,
with a separate 64 MiB aggregate decode-accounting budget. Nested accounting may
reject a request below the byte ceiling. These are bounded-service controls,
not a claim about whole-process memory or preemption of native storage reads.
The capacity permit and anonymous file remain owned through physical work;
download expiry runs even when a client stops polling.

The positive candidate uses a separate native Stock deadline producer's retained

Its scope is producer/export association and transport, not committed WSV
snapshot recovery, four live validators, funding or settlement. The original
Stock prestate contains an unqualified compiled profile; the public bundle does
not prove registry inclusion and must keep `profile_registered` false.
The [earlier producer evidence](native-street-producer-bundle.md) and
