# Draco mesh decoder

The WebAssembly decoder and wrapper are copied unchanged from the `three`
0.186.0 package, `examples/jsm/libs/draco/gltf/`. They decode the period coupe's
standard `KHR_draco_mesh_compression` geometry locally.

Draco is Copyright Google Inc., licensed under the Apache License 2.0.
The full [license](LICENSE) is retained here.

- [Upstream project](https://github.com/google/draco)
- [Three.js decoder distribution](https://github.com/mrdoob/three/tree/r186/examples/jsm/libs/draco)

No runtime network request to an external decoder CDN is needed.
