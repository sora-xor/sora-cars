# Driving asset derivatives

Generated from the unchanged, licensed originals in `public/assets` by `scripts/optimize-driving-assets.py`. The manifest retains each original and derived SHA-256 and size. Existing attribution and licenses beside the original models apply unchanged. Mesh, skin, node, animation and material identities remain unchanged; only image resolution/encoding changes. Roadside trees use the existing authored LOD2/3 geometry. Architectural geometry is losslessly gzip-compressed and verified against its original manifest after decompression.
